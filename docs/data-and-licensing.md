# 数据与许可

## 本仓库不含规范原文

工程规范文本受著作权保护，**本仓库只提供引擎、配套工具、测试与虚构样例**，不含任何真实规范条文、条文说明或图集图片。

因此：

- 仓库里的 `examples/sample-standards/` 是**完全虚构**的三本示例规范（标准号前缀 `SAMPLE`，条文号、数值、说明均为杜撰），只用于演示解析与检索链路，**不得作为工程设计的依据**
- 你手上的规范放在**你自己的数据目录**（`$STDQ_DATA_DIR`）里，不进这个仓库

## 引用规范文本时的注意

如果你的使用场景需要**对外输出**规范条文（例如做成检索服务、生成报告）：

- 条文原文的复制、传播属于著作权范畴，**先确认你的使用方式是否被允许**（合理引用与整体复制不是一回事）
- 强条、条文说明、图集图示的授权情况可能各不相同
- 本引擎只做"从你本地已有的文本里检索"，不对你如何使用检索结果作任何授权

## 贡献与提交

欢迎提交 bug 修复、工具改进、文档修正。提交时请注意：

- **不要**把任何真实规范原文、条文说明全文、图集图片贴进 issue、PR 或测试数据
- 需要举例时用 `examples/sample-standards/` 里的虚构样例，或自己写等价的虚构片段
- 新增测试请保证不依赖外网、不依赖未被声明的依赖（测试用标准库 `unittest`）
